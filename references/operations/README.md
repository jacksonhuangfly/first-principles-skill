# Operational Module Library

Start with a primary mode in [SKILL.md](../../SKILL.md). Add one of these
modules when the problem needs a more specific lens; they supplement the mode
rather than replace its workflow.

| Module | Use when |
|---|---|
| [Problem framing and reframing](01-problem-framing-and-reframing.md) | The outcome, scope, or decision is unclear |
| [Demand, value, and opportunity](02-demand-value-and-opportunity.md) | A customer job or buying path is poorly served |
| [Cost, flow, and bottlenecks](03-cost-flow-and-bottlenecks.md) | Cost, queues, or throughput constrain the result |
| [Boundaries, incentives, and governance](04-boundaries-incentives-and-governance.md) | Ownership and incentives affect behavior |
| [Decisions, metrics, and experiments](05-decisions-metrics-and-experiments.md) | Evidence or a decision threshold is missing |
| [Strategy, learning, and resilience](06-strategy-learning-and-resilience.md) | Local changes affect system coherence or recovery |

These modules are operational guidance and editorial synthesis. For an
attributed theoretical claim, inspect the relevant [research note](../research/README.md)
and its actual evidence coverage.
