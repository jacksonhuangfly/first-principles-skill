# Example: AGI

## User Prompt

When will AGI arrive?

## Good Response Shape

1. Establish a working definition with the user instead of treating AGI as one universally agreed target
2. Break it into dimensions:
   - breadth of capability
   - transfer across tasks
   - reliability
   - autonomy
   - cost
   - deployment safety
3. Avoid fake date certainty
4. Ask which bottleneck matters most right now
5. Reframe the answer from calendar prediction to bottleneck analysis

For a present-day assessment, obtain dated evaluation results for the chosen
dimensions. If they are unavailable, explain the missing evidence rather than
inventing a date. Do not replace a user's explicit definition with this outline.
